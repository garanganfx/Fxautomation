STEP 02 Access MetaTrader Root Storage Terminal
expand_more

Launch your desktop MT4 / MT5 platform. In the top navigation menu, navigate to:

File → Open Data Folder → MQL4 / MQL5 → Experts
STEP 03 Deploy Binary & Refresh Navigator Tree
expand_more

Paste the downloaded binary file directly inside the /Experts directory. Return to MetaTrader, press Ctrl+N to open Navigator, right-click "Expert Advisors", and click Refresh.

STEP 04 Authenticate WebRequest & License Validation Node
expand_more

Go to Tools → Options → Expert Advisors. Enable "Allow WebRequest for listed URL" and append the primary authentication gateway URL:

https://api.nexusfxalgo.com
STEP 05 Inject Institutional Risk Preset (.set)
expand_more

When loading the EA on your chart, click the Inputs tab, hit Load, and pick your preferred setting file (e.g., XAUUSD_Conservative.set). Ensure your license key is pasted into the InpLicenseKey variable.

STEP 06 Attach EA to Verified Execution Chart
expand_more

Open a clean chart with the specified instrument (e.g. XAUUSD on M15 timeframe). Drag and drop the EA from Navigator onto the chart canvas.

STEP 07 Engage 'Algo Trading' Engine (Green Icon)
expand_more

Ensure the top toolbar button marked Algo Trading or AutoTrading is engaged (Green Play Icon). A grinning emoji or green icon will populate the top right corner of your chart, confirming active algorithmic surveillance.
